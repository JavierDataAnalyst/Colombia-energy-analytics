What drives Colombia's electricity price?

Hydro plants produce most of Colombia's power, so you might expect the price to follow how full the reservoirs are. The data says something else: the price follows the rain.

–correlation of the spot price with hydro inflows
–with reservoir level: a weak signal

The 60-second version

What I found

The spot price tracks rainfall (hydro inflows), not reservoir level. In dry months it is about 3× higher than in wet months.

Why it matters

A company that buys power at the spot price can use inflows as an early-warning signal to decide when to lock in a fixed-price contract.

What I built

An automated, tested data pipeline: API ingestion, a dbt star schema, certified metrics and this page, refreshed every week.

PythonSQLdbtDuckDBGitHub Actions

Method

Data

XM public API (servapibi.xm.com.co): hourly demand, spot price and generation by plant; daily reservoir level and hydro inflows. Monthly aggregates over 46 complete months.

Metrics

Spot price is demand-weighted: Σ(price × demand) / Σ demand. Inflows are expressed as a share of their historical mean. Generation shares use plant-level data joined to plant technology.

Statistics

Pearson correlation and an OLS line on monthly values, recomputed in your browser for the period you pick. Descriptive only: no lags, no causal claim, no forecast.

Decision memo

Question
When should a spot-price buyer lock in a fixed-price contract?
Recommendation
Watch inflows vs. historical mean. Below 70 %, expect prices around three times the wet-month level. Reservoir level alone is a weak signal.

How it is built

Four layers, each reading only from the one before. Click a layer to see its models.

  1. Layer 1 · Sources

    Raw, untouched, never overwritten

    Python calls the XM API month by month, stores each response as received and rejects a month with any missing day or hour.

    etl/ingest.py
  2. Layer 2 · Model

    Star schema in dbt

    Facts by date × hour and date × hour × plant. Unknown plants go to an exceptions table, never dropped.

    dbt/models/core
  3. Layer 3 · Metrics

    Defined once, documented

    Weighted spot price, inflows vs. history, generation mix and hourly profile, each with a dictionary card.

    dbt/models/metrics
  4. Layer 4 · Product

    This page

    Reads only certified metrics. A weekly GitHub Actions job rebuilds, tests and republishes it.

    app/build_report.py

Metric definitions (SQL)

Data quality: every test can fail

Results of the latest dbt test run.

–

The accuracy test reconciles two independent XM publications, plant-level and system-level generation, every day. If they disagree by more than 0.5 %, or any other test fails, the weekly build stops and this page is not updated.
